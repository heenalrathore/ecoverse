# Sounds

Drop the following mp3 files in this folder to enable audio. The app loads them
lazily via Howler and stays silent if a file is missing — nothing breaks.

| Filename       | Used for                                  |
|----------------|-------------------------------------------|
| `forest.mp3`   | Ambient forest loop (Plant the Future)    |
| `ocean.mp3`    | Ambient ocean loop (Ocean Cleanup)        |
| `wind.mp3`     | Wind whoosh                               |
| `rain.mp3`     | Rainfall                                  |
| `thunder.mp3`  | Distant thunder                           |
| `birds.mp3`    | Birds chirping (Pollution Cleaner palm)   |
| `whoosh.mp3`   | Swipe / restoration cue                   |
| `chime.mp3`    | Generic positive cue                      |
| `pop.mp3`      | Seed plant / small event                  |
| `power.mp3`    | Energy generator power-up                 |

Free CC0 sources: freesound.org · pixabay.com/sound-effects · zapsplat.com
